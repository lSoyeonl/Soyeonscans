Soyeon Scans v1.1 — карточка маньхуа + редактор

Что изменено:
1. Исправлено переполнение длинных названий на карточках, вкладках и страницах маньхуа.
2. На странице каждой маньхуа добавлена отдельная информационная колонка:
   - обложка;
   - автор;
   - статус проекта;
   - оригинальное название;
   - команда перевода.
3. Статусы: Продолжается / Перерыв / Завершено / Не указан.
4. Добавлен отдельный блок «Описание».
5. Главы показываются с номером, названием, датой и несколькими ссылками на читалки.
6. Для каждой ссылки можно указать примечание.
7. Добавлен admin.html — редактор данных проекта.
   Админ может добавлять/удалять проекты, главы и читалки, редактировать описание/автора/статус.
8. Редактор сохраняет черновик в localStorage и позволяет скачать готовый data/manga.json.
9. Предпросмотр черновика работает через manga.html?...&preview=1.

ВАЖНО:
GitHub Pages — статический хостинг, поэтому браузер не может безопасно менять файлы репозитория сам.
Чтобы опубликовать изменения для всех:
- открыть admin.html;
- отредактировать данные;
- нажать «Скачать manga.json»;
- заменить data/manga.json в GitHub.

Для автоматической публикации прямо из админки без ручной загрузки нужен backend (например Supabase).
