# Soyeon Scans v1 — обновление проектов

Это отдельный сайт Soyeon Scans. Он не связан с сайтом «Легенды Кунг-Фу».

Добавлено на главную:
- «Бушующее Пламя Любви»;
- «Исключительное Увлечение Миллиардера».

У каждой маньхуа есть отдельная страница, а сверху на странице проекта есть вкладки для переключения между маньхуа.

Содержимое глав и описания намеренно не выдумывалось: их можно заполнить позже в `data/manga.json`.

Для GitHub Pages загрузите содержимое папки `Soyeon-Scans-v1` в отдельный репозиторий сайта Soyeon Scans.
